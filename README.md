# Desafio-Nvl-Heroi-DIO
Classificador de Nível de Herói 🦸‍♂️
Projeto desenvolvido como parte do desafio “Classificador de nível de Herói” da DIO, aplicando conceitos básicos de lógica de programação com JavaScript, como variáveis, operadores, estruturas de decisão e laços de repetição.​

🎯 Objetivo do Projeto
Criar um algoritmo que recebe o nome de um herói e sua quantidade de experiência (XP) e, com base nesse valor, classifica o herói em um dos seguintes níveis:​

Menos de 1.000 XP → Ferro

Entre 1.001 e 2.000 XP → Bronze

Entre 2.001 e 5.000 XP → Prata

Entre 5.001 e 7.000 XP → Ouro

Entre 7.001 e 8.000 XP → Platina

Entre 8.001 e 9.000 XP → Ascendente

Entre 9.001 e 10.000 XP → Imortal

Maior ou igual a 10.001 XP → Radiante

Ao final, o programa exibe a mensagem:

O Herói de nome {nome} está no nível de {nivel}

🧠 Tecnologias e Conceitos Utilizados
Linguagem: JavaScript

Conceitos:

Declaração e uso de variáveis

Uso de operadores lógicos e relacionais

Estruturas de decisão (if, else if, else)

(Opcional) Laços de repetição para testar vários heróis em sequência

🚀 Como Executar o Projeto
Clone este repositório:

bash
git clone https://github.com/SEU-USUARIO/SEU-REPOSITORIO.git
Abra o projeto em seu editor (por exemplo, VS Code).

Execute o código de uma das seguintes formas:

Em um arquivo .js ligado a um index.html no navegador (via console.log ou prompt).​

Em um ambiente Node.js, rodando:

bash
node index.js
Informe o nome e o XP do herói conforme solicitado e veja o nível exibido no terminal ou no console do navegador.
